RESONANCE — HTML / CSS / JAVASCRIPT EDITION

Files:
- index.html  — main application page
- styles.css  — complete responsive styling
- app.js      — questionnaire, browser-side scoring engine, result report

RUNNING:
1. Keep all three files in the same folder.
2. Double-click index.html.
3. The app opens directly in your browser. No Node.js, npm, server or internet connection is required.

NOTES:
- This version preserves the original 7-dimension questionnaire and deterministic scoring logic.
- The original React server-side calculation has been moved into app.js so the project can run entirely from a local HTML file.
